# Dbox Form Builder Platform

A dynamic, easy-to-use form builder that allows users to create, share, and collect data through custom forms — no coding required.

This project is designed with **African users in mind**, featuring offline support, local payment gateway integration, and multi-language options.

---

## 🚀 Features
- Drag-and-drop form builder
- Store form structures in JSON
- Collect and store form responses
- Offline and online support
- Payment integration (Paystack, Flutterwave, etc.)
- Multi-language support
- Works on desktop and mobile

---

## 🛠️ Tech Stack
### Backend
- Node.js + Express
- Prisma ORM
- PostgreSQL

### Frontend
- React.js
- Tailwind CSS
- Axios
